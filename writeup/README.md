4.  When lookahead distance is smaller, the robot has the capacity to follow paths with more curves or sharp turns and much more closely to how the path is drawn. When the distance is larger, it can get to the final point faster, but does not follow the path as it was designed. This happens because it "does not care" for what is inside the radius of distance: therefore, it does not realize there are curves designed in the path.
5. A smaller lookahead distance is more robust as it can follow smaller paths and more detailed paths without "skipping" over sections that include curves or tinier variations.
6.1 The final chosen parameters were 40 for both K and T. A smaller T did not "see" far away enough to catch that it would crash against an object, by the time it realized it was gonna crash it was too late and there was basically no way around it. The 40 T was good enough for making the turn on time. A bigger K makes the robot crash as well, as it assumes a certain steering angle is enough to evade the obstacle, what it fails to take into account is the width of the robot, so we can assume that not all steering angles are worth checking because, when checking an angle, there are a lot of other angles around it that will also fail as the car simply does not fit. Also, these parameters were chosen as "good enough" in the spirit of it being robust and use as little computational power as possible.
6.2 The codesaw track is not only difficult to track, it is impossible with the current algorithm. The car is always at a fixed velocity, there is no controller for that. The controller only changes the steering angle. Therefore, when making a turn it will never be in its own axis and always will do a small circumference. Assuming we can control the velocity, it would also be difficult to follow the exact path as sometimes the velocity would be to zero and then perfectly synchronize with the steering angle to rotate the exact amount of degrees. If we assume this car will be used for a real road (like a self driving car), this is just not feasible as natural objects tend to have a more organic way of moving which can be replicated better with the current algorithm.
